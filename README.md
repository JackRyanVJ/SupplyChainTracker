# Hot Wheels Supply Chain & Inventory Portal

An enterprise Next.js supply chain & inventory tracking portal built with real-time Supabase sync, RFC4122 v4 UUID barcoding, AI Vision product intake, and logistics telemetry.

## Features
- **Consolidated Stock Registry**: Real-time stock counts, damage quarantine numbers, and active asset valuation in INR (₹).
- **Serialized Tracking**: RFC4122 v4 UUID barcode generation for every individual casting.
- **AI Vision Pipeline**: Exact image matching and damage detection for quality control.
- **Logistics Telemetry**: Freight hub tracking, carrier transit milestones, and status exception handling.
- **Mobile Laser Scanner**: Interactive barcode laser camera simulation for rapid dock check-ins.
